Guide Intention

Construisez votre première interface, étape par étape.

Ce guide part de zéro, explique chaque décision et vous laisse modifier de vrais exemples Intention directement dans la page.

Intention transforme des descriptions lisibles en composants Web réactifs. Vous déclarez les données, les composants et les interactions ; le framework génère le rendu, maintient l'état synchronisé et utilise vos Web Components pour le design.

À qui s'adresse ce guide ?

Aux personnes qui découvrent le frontend comme aux développeurs expérimentés qui veulent produire une interface sans JSX, hooks ou balisage à fermer.

Guide ou référence ?

Le guide explique progressivement comment construire. La référence technique décrit exhaustivement la grammaire, les valeurs acceptées et le comportement exact de la v0.8.

Démarrage rapide

Une application locale en trois commandes.

Intention demande Node.js 20 ou plus récent. La commande init génère une application complète avec ses routes, pages, composants, assets et ses styles locaux.

Pré-requis

Vérifiez Node.js avec node --version. Toute version 20 ou plus récente convient.

Tutoriel

Un compteur réactif sans balisage.

Un composant rassemble son état et son interface. var crée une donnée réactive ; on click décrit l'interaction exactement là où elle se produit.

Dans l'éditeur ci-dessous, remplacez la valeur initiale, modifiez les libellés ou ajoutez un second message. Chaque changement est analysé par le vrai parseur Intention puis exécuté dans un aperçu isolé.

Compteur interactifEssayez count = 10, changez le texte ou ajoutez une condition.component App: var count = 0 computed doubled = count * 2 heading "Mon compteur" row: button "−": disabled if count == 0 on click: count = count - 1 text count button "+": on click: count = count + 1 message "Valeur doublée :" message doubled

Le point important

Il n'existe ni fonction de rendu ni appel manuel pour rafraîchir la page. Une affectation suffit : Intention recalcule seulement ce qui dépend de count.

Architecture

Des fichiers rangés comme dans un framework classique.

Le point d'entrée configure l'application. Les pages, composants, looks et assets sont découverts automatiquement, sans liste d'imports à maintenir.

Le langage

Une intention par ligne, deux espaces pour entrer dans un bloc.

Les deux-points ouvrent un bloc. Les paramètres sont nommés et séparés par des virgules. Les guillemets indiquent un texte littéral ; sans guillemets, Intention évalue une expression.

●●●
syntaxe.intentcomponent ProductCard: input title = "Produit" input price = 0 card: heading title message price button(variant: "brand", disabled: false) "Ajouter": on click: emit selected with title
component ProductCard: input title = "Produit" input price = 0 card: heading title message price button(variant: "brand", disabled: false) "Ajouter": on click: emit selected with title

Réactivité

var change, computed suit automatiquement.

Utilisez var pour une valeur locale modifiable. Utilisez computed pour une valeur dérivée : elle est recalculée depuis l'état courant, sans dépendances à déclarer.

●●●
price.intentcomponent Price: var quantity = 1 var unitPrice = 12 computed total = quantity * unitPrice message "Total" heading total button "Ajouter une unité": on click: quantity = quantity + 1
component Price: var quantity = 1 var unitPrice = 12 computed total = quantity * unitPrice message "Total" heading total button "Ajouter une unité": on click: quantity = quantity + 1

Choisir le bon mot-clé

var pour une source de vérité, computed pour une valeur que l'on peut toujours retrouver à partir d'autres données, memory pour une information technique qui ne doit pas provoquer de rendu.

Composition

Construisez de petits blocs qui se lisent seuls.

input définit le contrat public du composant. Le parent transmet les valeurs avec des paramètres nommés. slot choisit où afficher le contenu fourni par le parent.

●●●
components/Panel.intentcomponent Panel: input title = "Section" card: heading title slot component Home: Panel(title: "Profil"): message "Contenu fourni par Home" button "Modifier"
component Panel: input title = "Section" card: heading title slot component Home: Panel(title: "Profil"): message "Contenu fourni par Home" button "Modifier"

Les composants Intention deviennent des Custom Elements préfixés par intent-. Ils peuvent donc être utilisés dans une autre application Web et conserver leur état, leurs événements et leur encapsulation.

Interactions

L'événement est placé sous l'élément concerné.

on click, on change et on submit regroupent les actions déclenchées. if et else rendent les variantes explicites au même niveau que le reste de l'interface.

Collections

each répète, where filtre, key conserve l'identité.

Chaque élément de la collection reçoit un nom local. index indique sa position. Une key stable permet à Intention de préserver le bon état lors d'un tri ou d'une suppression.

Liste modifiableCliquez sur une tâche pour la retirer du tableau.component App: var tasks = ["Écrire", "Tester", "Publier"] heading "À faire" each task in tasks: card: heading task button "Terminer": on click: tasks -= task if tasks.length == 0: message "Tout est terminé !"

Placement

La grille annonce sa capacité, les enfants demandent leur place.

columns fixe le nombre maximal de colonnes. width et height forment un rectangle : Intention cherche la première zone où il tient entièrement et ne laisse jamais un autre bloc le chevaucher.

Grille en directEssayez columns: 2, gap: 32 ou changez les largeurs.component App: heading "Tableau de bord" grid(columns: 3, minimum: 150, gap: 12): card(width: 2): heading "Activité" message "Vue principale" card: heading "Équipe" message "12 membres" card: heading "Tâches" message "8 ouvertes"

Responsive sans media query

Lorsque l'espace devient trop étroit, Intention réduit le nombre de colonnes et replace les éléments dans leur ordre naturel.

Convention recommandée

Placez les thèmes et looks partagés dans styles.intent. Le compilateur le découvre automatiquement et l'autocomplétion propose les looks déclarés.

Échappatoire avancée

Gardez SCSS pour ce qui mérite vraiment du CSS.

Un composant peut associer un fichier .scss avec stylesheet. Le sélecteur :component représente sa racine ; le résultat est compilé, isolé dans son Shadow DOM et aussi appliqué au HTML SSR.

●●●
components/Feature.intentcomponent Feature: stylesheet = "./Feature.scss" section(class: "feature"): heading "Effet avancé" message "Les looks restent disponibles ici."
component Feature: stylesheet = "./Feature.scss" section(class: "feature"): heading "Effet avancé" message "Les looks restent disponibles ici."
●●●
components/Feature.scss:component { position: relative; .feature { background: linear-gradient(135deg, #6545f5, #9f8cff); &::after { content: ""; position: absolute; inset: -1px; border: 1px solid #ffffff40; } } }
:component { position: relative; .feature { background: linear-gradient(135deg, #6545f5, #9f8cff); &::after { content: ""; position: absolute; inset: -1px; border: 1px solid #ffffff40; } } }

Quel outil choisir ?

Commencez par theme et look. Utilisez SCSS pour les pseudo-éléments, sélecteurs complexes, animations sur mesure et effets graphiques. Le bloc style reste utile pour une correction locale minuscule.

Apparence

Une correction ponctuelle, directement dans le composant.

Le bloc style reprend les propriétés CSS sans accolades ni point-virgule. Réservez-le aux ajustements courts : pour un vocabulaire partagé utilisez look, et pour un style complexe préférez un fichier SCSS local.

Style en directChangez la couleur, l'espacement, le rayon ou la limite responsive.component App: style: host: display: grid grid-template-columns: 1fr 1fr gap: 20px padding: 32px host under 700: grid-template-columns: 1fr ".welcome": padding: 24px border: 2px solid #7658ff border-radius: 20px background: #ffffff heading: color: #6545f5 card(class: "welcome"): heading "Bienvenue" message "Ce style appartient seulement à App."

Isolation automatique

Chaque composant possède son Shadow DOM. Une règle locale ne peut pas modifier accidentellement un autre écran.

État avancé

Partagez sans Provider, persistez sans plomberie.

shared rend une valeur disponible dans tous les composants. action nomme une transition métier, do l'exécute et persist restaure automatiquement une valeur après rechargement.

●●●
cart.intentshared cart = [] component AddButton: input product = {} action add(item): cart += item notify "Ajouté au panier" button "Ajouter": on click: do add with product component Preferences: persist theme = "light"
shared cart = [] component AddButton: input product = {} action add(item): cart += item notify "Ajouté au panier" button "Ajouter": on click: do add with product component Preferences: persist theme = "light"
shared

Disponible partout

Une source de vérité réactive pour plusieurs composants.

Transition nommée

Regroupe plusieurs changements sous un nom métier.

Conservé localement

La valeur survit à la fermeture et au rechargement.

Pages

Une configuration de routes, du HTML déjà rendu.

Chaque route pointe vers un composant portant le même nom. Les routes statiques sont pré-rendues ; les paramètres dynamiques deviennent directement des inputs de page.

●●●
routes.intentroutes: Home: "/" Documentation: "/docs" Product: "/products/:id" NotFound: "*" component Product: input id = "" heading id button(href: "/docs") "Retour au guide"
routes: Home: "/" Documentation: "/docs" Product: "/products/:id" NotFound: "*" component Product: input id = "" heading id button(href: "/docs") "Retour au guide"

Un bouton avec href utilise automatiquement la navigation cliente après le premier chargement. L'historique, les boutons précédent/suivant et les ancres restent natifs.

Design

Le vrai nom de la bibliothèque, sans couche intermédiaire.

Déclarez Web Awesome ou un module local, puis utilisez directement wa-button, acme-card ou tout autre Custom Element. Les propriétés et événements ne sont jamais traduits.

Aucune configuration cachée

Le module JavaScript enregistre seulement ses Custom Elements. Intention n'attend aucun objet de mapping ou fichier de style global.
