Guide de démarrage

De zéro à votre première interface en cinq minutes.

Intention fonctionne avec Node.js 20 ou plus récent. Une commande crée la structure, puis le serveur local rassemble et compile automatiquement tous les fichiers du projet.

Initialisezintent init mon-projet crée app.intent, les routes, les pages, les composants et les assets.
Lanceznpm run dev démarre le compilateur et le serveur SSR local sur le port 4173.
CréezModifiez n'importe quel fichier .intent. Le navigateur reçoit automatiquement la nouvelle version.
intent init mon-projet && cd mon-projet && npm run dev
Consulter la référence
Terminalintent init mon-projet cd mon-projet npm run dev
app.intentapplication = "Mon application" start = Home

Manuel complet

Chaque notion expliquée, puis montrée avec du vrai code.

Parcourez les onglets dans l'ordre pour apprendre Intention, ou ouvrez directement le sujet dont vous avez besoin. Chaque partie contient plusieurs exemples prêts à adapter.

Créer et lancer une application

app.intent nomme l'application, choisit éventuellement un design system et indique le composant de départ. Le reste du projet se range par rôle.

Routing SSR

Une page se déclare comme une ligne de configuration.

Le serveur envoie déjà le contenu de la bonne page. Ensuite, Intention rend les navigations instantanées, conserve l'historique et active les Web Components.

NommezLe nom de la route correspond simplement au composant de page.
AssociezDonnez-lui une URL commençant par un slash.
NaviguezUn href vers cette URL utilise automatiquement le routeur.
app.intentroutes: Home: "/" Documentation: "/docs" Product: "/products/:id" NotFound: "*" component Product: input id = "" heading "Produit "

Questions fréquentes

Tout ce qu'il faut savoir avant de commencer.

Faut-il connaître HTML ou React ?Non. Intention décrit directement les composants, les données et les interactions. Quelques notions générales de logique suffisent pour commencer.
Puis-je utiliser mon propre design system ?Oui. Une simple table de correspondance relie les concepts Intention à vos Custom Elements, leurs propriétés et leurs événements.
Que se passe-t-il sans Web Component ?Intention utilise automatiquement un élément HTML natif équivalent. Un concept inconnu retombe sur un div neutre.
Le placement fonctionne-t-il sur mobile ?Oui. minimum définit la largeur souhaitée d'une colonne ; Intention réduit ensuite leur nombre et replace les composants dans l'ordre naturel.
L'autocomplétion connaît-elle mes composants ?Oui. L'extension VS Code détecte leurs inputs et les événements qu'ils émettent pour proposer les bonnes écritures au bon endroit.
