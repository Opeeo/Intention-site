Référence rapide

Le langage essentiel, sur une seule page.

Chaque concept suit la même logique : une intention par ligne, deux espaces pour entrer dans un bloc et des paramètres nommés quand ils sont utiles.

Routing SSR

Une page se déclare comme une ligne de configuration.

Le serveur envoie déjà le contenu de la bonne page. Ensuite, Intention rend les navigations instantanées, conserve l'historique et active les Web Components.

NommezLe nom de la route correspond simplement au composant de page.
AssociezDonnez-lui une URL commençant par un slash.
NaviguezUn href vers cette URL utilise automatiquement le routeur.
app.intentroutes: Home: "/" Documentation: "/docs" Product: "/products/:id" NotFound: "*" component Product: input id = "" heading "Produit {id}"
