Intention v0.8

Référence officielle du langage

Cette page décrit le comportement réellement implémenté par le parseur, le compilateur, le rendu SSR et le runtime navigateur. Le guide apprend à construire une interface ; cette référence définit précisément ce que chaque instruction accepte et produit.

Contrat de la v0.8

Une instruction par ligne, deux espaces par niveau, aucun import applicatif, un Shadow DOM par composant et des Web Components conservés sous leur vrai nom.

Origine des erreurs

Même si le compilateur assemble les sources, une erreur indique le fichier et la ligne d'origine.

Fondations

Grammaire, blocs et noms

La structure dépend uniquement des lignes et de l'indentation. Le caractère deux-points ouvre visuellement un bloc ; il est retiré avant l'analyse.

Règles lexicales
indentationdeux espaces2, 4, 6…Chaque bloc avance exactement d'un niveau. Les tabulations et les niveaux sautés sont refusés.
blocinstruction:: finalLe deux-points terminal est recommandé. L'indentation détermine réellement les enfants.
commentaire# texteligne entièreUne ligne dont le premier caractère non blanc est # est ignorée.

Une valeur est analysée comme un littéral connu ou comme une expression. Les listes et objets utilisent la syntaxe JSON.

interpolation"Bonjour "expression entre {}Disponible dans les chaînes littérales ; null et undefined deviennent du texte vide.

JSON strict

Une liste ou un objet commençant par [ ou { doit être du JSON valide. Les clés non citées et les virgules finales sont refusées.

État local, partagé, persistant et calculé

Les déclarations de données placées directement dans le composant sont initialisées une fois par instance. Une modification réactive relance le rendu du composant concerné.

Sources de données

Persistance tolérante

Si localStorage est indisponible ou contient un JSON invalide, Intention utilise la valeur initiale et continue sans bloquer l'interface.

Réactivité

Cycle de vie et effets

Les effets sont déclaratifs et doivent être placés directement dans le composant. Ils exécutent des actions, jamais du JavaScript arbitraire.

Déclencheurs
mounton mount:une fois par connexion initialeExécuté après le premier rendu de l'instance.
changeon change of expression:expression surveilléeMémorise la valeur initiale puis s'exécute lorsque sa représentation JSON change.
unmounton unmount:déconnexion durableExécuté en microtâche si l'instance n'a pas été reconnectée.

Boucles d'effet

Une action réactive déclenchée par un effet planifie un nouveau rendu. La condition surveillée doit donc converger pour éviter une boucle.

Sortie statique

build génère index.html pour chaque route statique, 404.html pour *, mais ne pré-génère pas les chemins dynamiques. dev et start rendent ces derniers à la demande.

Application

La commande intent pilote l'initialisation, le développement SSR, la compilation et le serveur de production local. Node.js 20 ou plus récent est recommandé.

Validation, erreurs et limites de la v0.8

Le parseur préfère refuser une ambiguïté plutôt que deviner. Les messages incluent le fichier, la ligne et la règle violée.

Erreurs vérifiées
indentationtabulation / niveau impairerreurDeux espaces exacts sont obligatoires.
déclarationvar = 1erreurUn nom valide est requis.
elseelse isoléerreurDoit suivre directement un if non événementiel.
JSON[1,]erreurLes listes et objets littéraux doivent être valides.
routesdoublon / composant absenterreurNoms, chemins et paramètres sont contrôlés.
sharednom répétéerreurUne source partagée ne peut être déclarée deux fois.
looknom répété / inconnu / cycleerreurLa composition et les breakpoints sont validés à la compilation.
SCSShors projet / sans :componenterreurLa feuille doit être relative, locale et posséder une racine explicite.
Web Awesomewa-* absenterreurLe composant doit exister et library = "webawesome" doit être déclaré.
Limites intentionnelles actuelles
expressionspas d'appel de fonctionopérateurs + cheminsLe langage n'exécute pas de JavaScript arbitraire.
actionsun paramètreaction name(item)Les routines nommées acceptent au plus un argument en v0.8.
ressourcesGET fetchJSON ou textePas encore de méthode, headers, cache ou mutation configurables.
formulairesbind + événementsvalidation nativePas encore de schéma de validation Intention dédié.
routessegments statiques ou :parampas de gardePas encore de route optionnelle, redirection ou garde déclarative.
hydratationactivationrerendu clientLe HTML SSR est remplacé lors du montage ; une hydratation conservatrice est prévue plus tard.
