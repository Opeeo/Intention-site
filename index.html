Une autre façon de construire

La puissance d'un framework moderne, sans sa charge mentale.

Intention retire la syntaxe accidentelle pour vous laisser penser au produit, aux interactions et aux utilisateurs.

Lisible immédiatement

Variables, composants et événements emploient des mots et des signes familiers.

Réactif par défaut

Modifiez une donnée. L'interface se remet à jour, sans hook ni gestion manuelle du DOM.

Placement naturel

Une grille fluide, des largeurs simples et un repli mobile automatique.

Web Components natifs

Branchez un design system existant ou laissez Intention utiliser le HTML natif.

Pas d'enfermement

Chaque composant Intention devient un véritable Custom Element utilisable partout.

Du prototype au produit

La même écriture couvre l'état, les listes, les conditions et les interactions complexes.

Une syntaxe qui parle

Pas de balisage à fermer, pas d'accolades imbriquées, pas de convention cachée. Deux espaces suffisent à raconter la hiérarchie.

Une démo complète

Les concepts avancés restent lisibles.

Cette démonstration utilise réellement shared, action, do, slot, where, key, computed et reset. Essayez-la : aucun code JavaScript applicatif n'est nécessaire.

catalog.intentshared cart = [] component Panel: input title = "Produit" card: heading title slot component Catalog: action add(product): cart += product each product in products where product.available key product.id: Panel(title: product.name, key: product.id): button "Ajouter": on click: do add with product button "Vider": on click: reset cart
